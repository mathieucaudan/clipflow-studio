Local-first creator toolkit

From long-form moments
to short-form stories.

ClipFlow Studio is a developer project for preparing, reviewing, and sharing short-form videos using local editing and AI-assisted workflows. TikTok account access is optional and requires account-holder authorization.

01 · Prepare

Analyze source footage and identify suitable moments and layouts.

02 · Review

Preview crops, titles, audio and finished vertical videos before sharing.

03 · Upload

Where enabled and authorized, send approved content to a connected TikTok account using TikTok's official API.

Respect creators' rights.

Only use footage that you own or have permission to republish. ClipFlow Studio does not grant rights to third-party videos. TikTok posting features are subject to TikTok review and availability.

About the project

This is an independently developed local application, not an official TikTok or Twitch product. Its public website provides information about the project, user terms and privacy practices. It does not host a public video-upload service.

Support and privacy enquiries: GitHub repository issues. Please do not post access tokens, passwords or private information in public issues.
